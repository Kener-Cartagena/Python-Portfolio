# Python Development Portfolio
This repository contains a diverse collection of Python projects, ranging from financial management tools to inventory systems and API integrations.

## 🌟 Featured Project: Finance Manager (Streamlit)
**`gestor_finanzas/`**
* **Description:** A sleek, personal finance dashboard built with **Streamlit** to track stock market investments and total net worth.
* **Key Features:** Manual data entry for capital tracking, real-time gain/loss visualization, and persistent storage using JSON.
* **Tech Stack:** Python, Streamlit, JSON.

---

## 📈 Finance & Investment Tools

### Investment Manager (API Integration)
* **`GestorInvestments/`**
* Automated portfolio tracker that fetches real-time data using the **Yahoo Finance API**. It manages data persistence via CSV files.

### Compound Interest Calculator
* **`Calculadora/`**
* A specialized tool to project investment returns based on custom time horizons and percentage yields.
